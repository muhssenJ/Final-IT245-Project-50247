# Final-IT245-Project-50247

## How to Run the Project

1. Clone or download the project from GitHub.
2. Make sure Java (JDK) is installed on your computer.
3. Open a terminal inside the project folder.
4. Compile the program:
   javac BookInquirySystem.java
   
6. Run the program:
   java BookInquirySystem
   
7. The program will test several book titles using both ArrayList and Binary Search Tree (BST) and display the results in the terminal.
